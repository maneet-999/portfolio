# Maneet | Portfolio

Personal portfolio built with React, Vite, Tailwind CSS, Framer Motion, GSAP, Lenis and Spline.

## Run

    npm install
    npm run dev

## Edit your content

- Projects: `src/data/projects.js` (liveUrl / repoUrl optional per project)
- Hero roles and greetings: `src/components/hero.jsx`
- About text: `src/components/About.jsx`
- Education / experience tree: `src/components/Education.jsx`
- Stack logos: `src/components/Skills.jsx`
- Links: `src/components/SocialMagnet.jsx`
- Resume: drop your PDF at `public/resume.pdf`

Based on https://github.com/Deadcoder001/React-Personal-Portfolio (MIT).
